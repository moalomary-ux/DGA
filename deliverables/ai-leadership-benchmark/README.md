# DGA AI Leadership Benchmark — الإخراج التنفيذي النهائي

تحويل الدراسة المعيارية «تطوير القيادات الحكومية العليا في الذكاء الاصطناعي» (v3.1)
إلى إصدار تنفيذي مصمم وفق الهوية البصرية المعتمدة من ريان المصمم — بنسختين متطابقتين
(عربية وإنجليزية) بصيغتي PPTX قابلة للتحرير وPDF جاهز للمشاركة والطباعة.

## خلاصة الالتزام بالمتطلبات

- **الهوية**: ألوان ريان الملزمة (2A206A / 7C32C9 / 00ABAF / 1CC182) وخط Diodrum Arabic
  — الخط نفسه المضمّن في ملف التصميم المرجعي — وأسلوب الغلاف وفواصل الأقسام والبطاقات
  والجداول والتذييل كما في المرجع، بمقاس A4 عمودي دون تحويل إلى 16:9.
- **المحتوى**: تحرير تنفيذي خفيف فقط؛ كل الحقائق والأرقام والأسعار والتواريخ وأسماء
  البرامج والاستنتاجات والتوصيات وعلامات المصادر [1]–[71] محفوظة.
- **المصطلحات**: صفر Undersecretary/Assistant Undersecretary؛ نائب الوزير = Vice
  Minister؛ وكيل الوزارة = Deputy Minister؛ الوكيل المساعد = Assistant Deputy
  Minister؛ مساعد الوزير ثابت في المستوى الثاني.
- **المسارات الأربعة**: بناء محلي / تطوير مشترك / شراء وتكييف / ترخيص وتوطين وتوسيع —
  دون تغيير.
- **التكلفة**: حصراً SAR 45,000–94,000 للمشارك و1.35–2.8 مليون ريال للفوج، موسومة
  تقديرات استرشادية لا عرض سعر.
- **التطابق الثنائي**: 39 = 39 صفحة، والجداول والرسوم والألوان والتسلسل القصصي متطابقة.

## إعادة البناء — Rebuild

```bash
cd generator
pip install python-pptx pillow fonttools lxml openpyxl python-docx
# تثبيت خطوط Diodrum Arabic في النظام ثم:
python3 build.py            # يبني النسختين + PDF عبر LibreOffice
python3 make_reports.py     # يولد تقريري الجودة
```
