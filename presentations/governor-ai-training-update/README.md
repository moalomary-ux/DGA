# التدريب في الذكاء الاصطناعي — تحديث لمعالي المحافظ (5 أكتوبر 2026)

عرض تنفيذي بهوية هيئة الحكومة الرقمية، مبني على **قالب الهيئة العربي الرسمي** (`DGA Template Ar.pptx`) من مهارة «DGA PPTX Designer».

## الملفات

| الملف | الوصف |
|---|---|
| `ai-training-governor-update-2026-10-05.pptx` | العرض النهائي: 36 شريحة ظاهرة + 5 شرائح داخلية **مخفية** (ملاحظات الإعداد وسجل الإثبات). ملاحظات المتحدث مضمّنة في كل شريحة. |
| `ai-training-governor-update-2026-10-05.pdf` | معاينة PDF نظيفة (بدون الشرائح الداخلية) بخط Diodrum مضمّن — احتياطًا إن لم يتوفر الخط على جهاز العرض. |
| `build_deck.py` + `slides_*.py` + `components.py` + `deck_*.py` | مصدر البناء (python-pptx). النصوص كلها في `slides_*.py` و`notes_data.py`. |

## بنية العرض

1. **الغلاف** ← **هدف العرض ومحاوره** ← **الملخص التنفيذي** (3 شرائح)
2. **القسم 1 — أين وصلنا؟** (ص 4–7): الأدوار، الاجتماعات، الإنجاز
3. **القسم 2 — النموذج المقترح** (ص 8–13): خيارات التصميم، الإطار، المسارات الثلاثة، فرضية 130 ألف، البيانات
4. **القسم 3 — تصميم المسارات والشراكات والتمويل** (ص 14–19)
5. **القسم 4 — التنفيذ والقياس والتوجيهات** (ص 20–23) — التوجيهات الأربعة المطلوبة من معاليه في ص 23
6. **الملاحق** (ص 24–36): ملاحق 1–5 والمراجع
7. **داخلي — مخفي** (ص 37–41): ملاحظات الإعداد وسجل الإثبات — تُحذف قبل مشاركة الملف خارج الفريق

> عرض مخصص جاهز: **«إحاطة موجزة للمحافظ (9 شرائح)»** — في PowerPoint: عرض الشرائح ← عرض شرائح مخصص.

كل شريحة تحمل في ملاحظاتها: رقمها في النص الأصلي، ملاحظات التقديم، حالة المحتوى، المرجع، وبند سجل الإثبات.

## إعادة البناء

```bash
pip install python-pptx lxml uharfbuzz fonttools pillow
npm install                      # react-icons + sharp (لأيقونات Phosphor)
export DGA_SKILL_DIR=<مسار مهارة dga-pptx-designer>   # القالب والخطوط
python3 build_deck.py --out out.pptx                  # الملف الكامل
python3 build_deck.py --no-internal --out preview.pptx # بدون الشرائح الداخلية (لتصدير PDF)
```

## بنود تحتاج حسمًا قبل التداول

- **تعارض أرقام:** الشريحة 5 (النص الأصلي) تذكر **272** موظفًا لثمانية برامج، بينما الشريحة 14 والملحق 3 وسجل الإثبات تذكر **222**.
- **التصنيف:** التذييل «عام - Public» كما تشترط الهوية؛ المحتوى قد يستوجب «مقيّد».
- **الخطوط:** الخطوط المضمّنة في القالب جزئية؛ ثبّت Diodrum Arabic على جهاز العرض.
- بيانات ناقصة: تواريخ الاجتماعات (ملحق 2)، أسماء الجهات الخمس، حالة ردود الجهات الـ52، تاريخ قطع الأرقام.
